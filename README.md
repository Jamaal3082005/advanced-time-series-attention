
# Advanced Time Series Forecasting with Attention

This project implements an attention-augmented LSTM model for multivariate
time series forecasting. It demonstrates improved performance and
interpretability compared to standard LSTM models.

## Features
- Multivariate time series preprocessing
- LSTM with Bahdanau Attention
- Baseline LSTM comparison
- RMSE evaluation metric
- Built using TensorFlow and NumPy

## How to Run
```bash
pip install -r requirements.txt
python src/train.py
